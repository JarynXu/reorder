# Security Policy

`reorder` rewrites source code, so correctness and source preservation bugs are treated seriously even when they are not conventional security vulnerabilities.

For ordinary bugs, open a GitHub issue with a minimal reproducer. If a report contains sensitive information or describes a security impact that should not be public before a fix exists, use GitHub's private vulnerability reporting flow when it is available for this repository.

Supported versions are the latest released minor version and the current `main` branch.
