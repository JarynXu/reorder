# Code of Conduct

Contributors and maintainers are expected to keep project interactions professional, technical, and respectful. Harassment, personal attacks, discrimination, threats, and deliberate disruption are not acceptable.

Project decisions should be discussed on their technical merits and with enough context for others to review them. Maintainers may edit, hide, or remove abusive content and may restrict participation when necessary to protect the project community.

Report conduct concerns to the repository maintainers through GitHub. Reports should include enough context to investigate while avoiding unnecessary publication of private information.
